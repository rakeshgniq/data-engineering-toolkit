# Data Engineering Toolkit

A centralized collection of utilities and automation scripts designed to simplify common data engineering tasks.

## Features

- AzCopy-based data migration and synchronization
- Pipeline creation and deployment automation
- MySQL query execution utilities
- Data ingestion and export tools
- Platform administration scripts
- Developer productivity helpers

## Repository Structure

├── azcopy/
├── pipelines/
├── mysql/
├── migration/
├── utilities/
└── docs/

## Purpose

Reduce manual effort, improve consistency, and accelerate developer workflows across data platform operations.
