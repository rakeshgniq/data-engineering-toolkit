What the toolkit does

Everything an engineer needs to move SingleStore pipelines safely between environments.

Export Pipelines

Dump every CREATE PIPELINE definition from a database into one idempotent SQL file.

Generate SQL Scripts

Produce ready-to-run CREATE OR REPLACE statements you can review, version and share.

Execute SQL

Run any .sql file statement by statement with progress, failure summary and a dry-run mode.

Pipeline Synchronization

Export from one database, apply to another — a repeatable two-step promotion flow.

Developer Utilities

Bash-first helpers that run on your laptop. No servers, no clusters, no stored credentials.

Best Practices

Dry-run first, never commit passwords, keep exports out of git — baked into every tool.
