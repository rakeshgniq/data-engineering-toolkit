Pipeline Export & Sync stable

Exports every CREATE PIPELINE definition from a SingleStore database into one idempotent pipelines.sql, then re-applies it statement by statement. Runs on your machine in bash — nothing is sent to this site, and your password is prompted locally and never stored.

Generate your command

Fill in connection details — the bash commands on the right update live. Password is intentionally not a field: the script prompts you for it.

🔒 Nothing you type here leaves your browser. Values are only used to build the command text below.

1 · Install (one time)

curl -sL https://raw.githubusercontent.com/rakeshgniq/data-engineering-toolkit/main/install.sh | bash -s singlestore-pipeline-sync

2 · Run

cd ~/data-engineering-toolkit/singlestore-pipeline-sync
bash run_all.sh --dry-run

You will be prompted for the password (masked). Remove --dry-run to apply.

Already installed? Run directly

bash run_all.sh --dry-run

How it works

  1. Export

    export_pipelines.py runs SHOW PIPELINES then SHOW CREATE PIPELINE for each, rewrites them to CREATE OR REPLACE, and writes pipelines.sql.

  2. Dry run

    run_sql_file.py --dry-run parses the file and lists every statement without touching the database. Review this first.

  3. Apply

    Same script without --dry-run executes each statement, prints OK/FAIL per statement and a summary. Exit code is non-zero if anything failed.
